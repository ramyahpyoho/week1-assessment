
# Week 1 Assessment - Python & Data Engineering

## Project Overview
This project demonstrates Python programming, file handling, API requests, NumPy, Pandas, data cleaning, visualization, and Git workflows.

## Project Status
Initial project setup completed. Python and data engineering assessment tasks have been completed on the feature/analysis branch.

## Setup Instructions

1. Create a virtual environment:

   python -m venv .venv

2. Activate it:

   .\.venv\Scripts\Activate.ps1

3. Install dependencies:

   pip install -r requirements.txt

## Project Structure

- data/ - Input CSV files
- src/ - Python source files
- notebooks/ - Jupyter notebooks
- reports/ - Generated charts
- task1/ - Python core programming
- task2/ - File handling and API
- task3/ - NumPy, Pandas and visualization
