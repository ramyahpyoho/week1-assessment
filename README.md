
# Week 1 Assessment - Python & Data Engineering

## Project Overview
This project demonstrates Python programming, file handling, API requests, NumPy, Pandas, data cleaning, visualization, and Git workflows.

## Setup Instructions

1. Create a virtual environment:

   ```bash
   python -m venv .venv
   ```

2. Activate it on Windows PowerShell:

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the analysis scripts:

   ```bash
   python task1/task1_python_core.py
   python task2/task2_files_api.py
   python task3/task3_analysis.py
   ```

## Project Structure

- `data/` - Input CSV data
- `src/` - Python scripts and notebook export
- `notebooks/` - Jupyter notebooks
- `reports/` - Generated charts
- `task1/`, `task2/`, `task3/` - Assessment task files
